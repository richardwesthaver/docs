* Overview
This manual is intended for developers of the [[vc:core][core]] software suite. The
[[vc:infra][infra]] project is designed to fully provision machines for *operators*
in our ecosystem.

* Introduction
:PROPERTIES:
:ID:       12988dd2-3367-4a11-aec5-c6fed1539cbc
:CREATED:  <2025-11-05 Wed 19:35>
:END:
This manual is written for [[id:4c7530b8-6d6f-475a-b2a3-986a10a0d812][x86_64]] systems, but accounts for [[id:4555306b-b68c-43a9-8a54-e4066ca7437d][Intel]] vs
[[id:e2368655-59e9-404b-9ac6-cecb35216c11][AMD]] CPU optimizations.

We may support other targets for specific purposes but when talking
about an *operator machine* we are refering specifically to the
~x86_64~ core linux build with all of our libraries
pre-installed. There is no guarantee that the core software suite will
function correctly outside of our environment.

* Overview
:PROPERTIES:
:ID:       2015b333-bc24-40ea-b9ad-2f514b57b83b
:CREATED:  <2025-11-05 Wed 20:07>
:END:
The project [[vc:infra/file/tip/skelfile][skelfile]] pulls in our utilities from [[vc:infra/file/tip/util.lisp][util.lisp]] in the
project root and contains a long list of rules which use the files in
the [[vc:infra/file/tip/scripts/][scripts]] directory. These rules are called via the =skel= cli tool
to build all of our dependencies from source, package, and deploy
them.

There are several sub-projects inside infra:
- [[vc:infra/home][home]] :: home directory management
- [[vc:infra/pod][pod]] :: [[id:89199dcd-fabd-4952-b5e9-1b3ffaf06e6b][Podman]] containers
- [[vc:infra/box][box]] :: [[id:06ee60a3-9a98-40d2-893b-39ce992fc0dc][Archiso]] and [[id:c4f26ef4-a936-4cf3-8218-4d23dbd9b33a][QEMU]] configs

- *Host Requirements*
  - x86_64
  - 8G RAM

- *Minimum Dependencies*
  - mercurial
  - git
  - zstd
  - openssl

If you're already running Arch Linux you can download PKGBUILDs from
our package archive and use =makepkg= to install them.

Make sure to download and add our [[packy:data/rwest.gpg][GPG key]]:
#+begin_src shell
curl https://packy.compiler.company/data/rwest.gpg -o /tmp/rwest.gpg
sudo pacman-key --add /tmp/rwest.gpg
sudo pacman-key --finger 196FA2C31A5821D0
#+end_src

#+RESULTS:

Then use the provided [[vc:infra/file/tip/scripts/install.sh][scripts/install.sh]] script to build and install
all dependencies.
