#+author: Richard Westhaver

=net= is the core networking library. Various Protocols and
network-specific codecs are supported in the =NET/PROTO= and
=NET/CODEC= mods respectively including =SWANK=, =DNS=, =OSC=, and
=HTTP=. The =NET/SRV= mod provides network-backed services based on
the =OBJ/SRV= protocol.

In general we /prefer/ UDP sockets, especially for internal
communications, but the most common modules used are likely =NET/REQ=
which provides http/s client support and =NET/SRV/HTTP= which provides
http/s server support.

** core
:PROPERTIES:
:ID:       040f67f5-901e-4686-a9c6-54aa245eeacf
:CREATED:  <2025-07-06 Sun 21:58>
:END:
The core network package provides base protocol definitions including
conditions, generic functions, and classes. In general our approach is
to extend =SB-BSD-SOCKETS=, not replace it, and to mix in a very
minimal API which resembles that of =USOCKET=. Most objects (including
sockets) can be configured via the =OBJ/CONFIG= protocol.

Similar to =IO/STREAM= and in the case of =STREAM-SOCKET= actually
subclassing it, we provide a =WRAPPED-SOCKET= class which contains the
underlying =SB-BSD-SOCKETS= class - either =INET-SOCKET= or
=INET6-SOCKET=.
