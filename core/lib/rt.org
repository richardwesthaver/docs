#+title: rt
#+author: Richard Westhaver
#+description: Core Regression Testing Library
#+setupfile: ../../../clean.theme

=rt= is a test framework inspired by the SBCL contrib with the same
name - the =SB-RT= package. In addition to regression testing this
library includes packages for various testing and debugging
shenanigans.
