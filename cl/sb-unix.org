* SB-UNIX
:PROPERTIES:
:ID: SB-UNIX
:LOCK: T
:END:
private: a wrapper layer for SBCL itself to use when talking with
an underlying Unix-y operating system.  This was a public package in
CMU CL, but that was different.  CMU CL's UNIX package tried to
provide a comprehensive, stable Unix interface suitable for the end
user.  This package only tries to implement what happens to be needed
by the current implementation of SBCL, and makes no guarantees of
interface stability.

** UNIX-SETITIMER :compiled:function:
:PROPERTIES:
:ID: SB-UNIX:UNIX-SETITIMER
:ALLOC: HEAP IMMOBILE
:END:
 
#+begin_example

UNIX-SETITIMER names a compiled function:
  Lambda-list: (WHICH INT-SECS INT-USEC VAL-SECS VAL-USEC)
  Derived type: (FUNCTION
                 ((MEMBER :REAL :VIRTUAL :PROFILE) UNSIGNED-BYTE (MOD 1000000)
                  UNSIGNED-BYTE (MOD 1000000))
                 (VALUES (MEMBER T) (UNSIGNED-BYTE 63) (MOD 1000000)
                         (UNSIGNED-BYTE 63) (MOD 1000000) &OPTIONAL))
  Documentation:
    UNIX-SETITIMER sets the INTERVAL and VALUE slots of one of three system
    timers (:real :virtual or :profile). A SIGALRM, SIGVTALRM, or SIGPROF
    respectively will be delivered in VALUE <seconds+microseconds> from now.
    INTERVAL, when non-zero, is reloaded into the timer on each expiration.
    Setting VALUE to zero disables the timer. See the Unix man page for more
    details. On success, unix-setitimer returns the
    old contents of the INTERVAL and VALUE slots as in unix-getitimer.
  Source file: SYS:SRC;CODE;UNIX.LISP

#+end_example
